Thank you for checking out Murder on the Dancefloor.
if you would like to play this game the current version to run on is Unity 6000.3.15fl
the controls are WASD to walk around, E to interact, mouse to look around, and SPACE to cycle through dialogue.
this project was made  by Marina Dawson, with assets made from sratch by myself in Maya. however there are some assets sourced from Sketchfab. They are as following
gun, HotdogHans. The ultimate glass pack (cups and bottles) Helind. VIP Rope Barrier, RM3DB. Kitchen Knife, Wyatt. Garbage bags, DjMaesen. Low poly Pack Alcohol bottles, DeangNu. And on Itch.io Characters PSX by elbolilloduro.
